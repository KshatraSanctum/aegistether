# AegisTether: Autonomous SRE Incident Bastion

AegisTether is an autonomous incident remediation agent built on the **TrueForge** agent harness. It intercepts high-severity telemetry alerts, triages root causes using the Model Context Protocol (MCP), tests remediation scripts in an isolated sandbox, and halts for a human-in-the-loop SRE authorization gate before deploying to production.

## 🏗️ Architecture & TrueForge Harness Integration
This project strictly leverages the TrueForge core lifecycle components:
1. **MCP Connectivity (`mcp-servers/cluster-mcp.ts`)**: Reaches external cluster telemetry and git diffs dynamically, bypassing hardcoded mock LLM data.
2. **Sandbox Isolation (`sandbox/executor.ts`)**: Code generated by the agent is executed in a simulated dry-run environment to validate Kubernetes routing integrity before deployment.
3. **The Approval Gate (`ui/server.ts`)**: Once the TrueForge loop determines an action is irreversible (e.g., a production rollback), the harness pauses execution and exposes a visual Bastion Dashboard for the on-call engineer to authorize.

## 🚀 Running the Project Locally

No Docker is required. The harness runs in standalone mode.

1. **Install Dependencies**
   ```bash
   npm install
   ```
2. **Set up Environment**
   Create a .env file in the root directory and add your LLM provider key:

   ```Code snippet
   GEMINI_API_KEY=your_api_key_here
   ```
3. **Start the MCP Tool Server**
   ```bash
   npx tsx mcp-servers/cluster-mcp.ts
   ```
4. **Run the AegisTether Agent (In a separate terminal)**

   ```bash
   npx tsx agent/index.ts
   ```
5. **Access the SRE Bastion Gate**
   When the agent pauses for human approval, open http://localhost:3000 to view the incident dossier and authorize the rollback.
